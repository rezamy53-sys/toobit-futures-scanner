راهنمای فارسی اسکنر فیوچرز Toobit

این نسخه فقط داده‌های عمومی بازار را می‌خواند و هیچ سفارش واقعی ثبت نمی‌کند.

مراحل انتشار در Render:
1- فایل ZIP را استخراج کنید.
2- فایل‌های داخل پوشه را در یک مخزن GitHub قرار دهید.
3- در Render وارد حساب شوید و گزینه New > Blueprint را انتخاب کنید.
4- مخزن GitHub را متصل کنید تا Render فایل render.yaml را پیدا کند.
5- پس از پایان Deploy، آدرس سایت ساخته‌شده را باز کنید.

نیازی به API Key یا Secret نیست.
اسکن نمادها دسته‌ای و 20تایی است؛ برای دسته بعدی دکمه «اسکن دسته بعدی» را بزنید.
تایم‌فریم‌ها: 15m، 30m، 1h.
شاخص‌ها: RSI، MACD، EMA، فیبوناچی، ایچیموکو، Bollinger، Stochastic و OBV.
داده‌های آن‌چین در این نسخه وجود ندارد.
سیگنال‌ها صرفاً ابزار غربالگری‌اند، نه توصیه مالی.
